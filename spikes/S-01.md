# S-01  Brackets to content controls bound to library columns

## Inputs
- Four templates from the owner's legal pack, held locally and never committed: an NDA, a services agreement, a DPA and a non-English notice
- their bracket list

## Outputs
- spikes/findings/S-01.md

## Steps
1. With the Open XML SDK or python-docx, replace three bracket occurrences in the mutual NDA template with plain-text content controls bound to custom document properties, preserving run formatting.
2. Upload to a test library whose columns have the same names; confirm SharePoint maps the properties to the columns.
3. Set the columns on a copy through the SharePoint connector's update-file-properties action and through PnP; open in Word desktop and Word for the web; confirm the controls show the values.
4. Repeat for an occurrence inside a table cell, in a header, in a footer, and for a multi-line value.
5. Test a bracket split across runs and a nested bracket.
6. Check the round trip: export to PDF from the filled file shows the values.
7. Record the binding method that works (document properties or content-type columns) and every limit found.

## Human steps
- None.

## Exit criteria
- Values set on the library item appear in body, table, header and footer in desktop and web Word.
- The PDF export shows the values.
- The finding names the method T4-02 must use, or states that the free route fails and proposes `upgrades/word-template-fill.md` as required.
