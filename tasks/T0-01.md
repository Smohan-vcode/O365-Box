# T0-01  Configuration schema and repository checks

## Inputs
- docs/SPEC.md §4, §7, §9, §19, §20, §21
- defaults/structure.yaml, defaults/mail.yaml
- flows/catalogue.yaml, expected-state/standard-connectors.yaml

## Outputs
- Go module and `box` binary (engine/cmd/box)
- schema/box-config.schema.json
- examples/acme/box-config.yaml and examples/acme/dictionary.yaml (fictional)
- commands: `box config validate [--for <task>]`, `box check-literals`, `box check-connectors`
- Go tests with a failing fixture for each command

## Steps
1. Create the Go module and the `box` command with sub-commands, `--json` output and the exit codes in SPEC §18.7.
2. Write the configuration schema: every section listed in SPEC §9.1; `secrets` values must be references (`keychain:` or `github:`); `structure` follows defaults/structure.yaml.
3. `box config validate <file>`: schema errors plus semantic checks: references between users, groups, mail objects and site access resolve; flow owner and break-glass accounts are users; permission guardrails of SPEC §7; overrides name catalogue settings and carry a reason; module dependencies hold. Report every error with its path.
4. `--for <task>`: also fail on empty values the task's front matter lists under `config_required`.
5. Write examples/acme with fictional values that pass validation.
6. `box check-literals`: collect company values (company names, entity wording, domains and their first label, people's names, tenant ID, dictionary values of four characters or more) from `--from-file` or, by default, examples/acme; scan every text file outside .git and the source of those values; also flag private keys and token patterns. `--from-tenant` returns a clear 'available after T0-06' error until then.
7. `box check-connectors`: every connector in flows/catalogue.yaml and every connector API referenced in flows/solution/ is in the allow-list.

## Human steps
- None.

## Exit criteria
- Each command passes on the repository and fails on its fixture, naming the file, line or path and the cause.
- `go vet` and `go test ./...` pass.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
