# T5-09  Company data change and notices (F11, F12, F19)

## Inputs
- Dictionary, Bindings, Notices

## Outputs
- flows F11, F12, F19

## Steps
1. F11: on a value change write Events; flag SENT documents whose template uses the key; create a PENDING_APPROVAL Notices item per published or record template using it.
2. F12: on approval, fill a new rendered copy, supersede the earlier one, set next review; publication URL is entered by the owner.
3. F19 weekly: raise review tasks at next_review_on.

## Human steps
- None.

## Exit criteria
- Changing one constant used by three notices creates three pending items.
- Approving one yields a new rendered file and supersedes the old.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
