# T5-05  Signature hand-off and executed filing (F05, F06)

## Inputs
- SPEC section 11

## Outputs
- flows F05, F06

## Steps
1. F05: task to holders of the signer role with the file link and signer details; on completion set SENT and sent_at.
2. F06: on a file in Executed inbox, extract the reference from the name; no match moves the file to an Unmatched folder and alerts.
3. On match: move to the counterparty folder as `<date>_<counterparty>_<code>_EXECUTED`; remove edit rights on the file; set EXECUTED, effective and expiry dates; call F07.

## Human steps
- Send each document for signature and upload the executed copy (until the signature upgrade).

## Exit criteria
- A correctly named PDF moves a SENT document to EXECUTED and is read-only.
- A wrongly named PDF is parked and reported.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
