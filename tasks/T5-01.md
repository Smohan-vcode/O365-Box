# T5-01  Solution scaffold and deployment

## Inputs
- flows/catalogue.yaml
- spikes/findings/S-03.md

## Outputs
- flows/solution/ source
- command: box apply flows

## Steps
1. Create the solution with connection references and environment variables for site URLs, list ids and the inbound token.
2. Deploy by the S-03 method; bind connection references to the flow owner's connections.
3. Shared scopes in every flow: error handler that writes Automation logs and mails alerts on second consecutive failure.

## Human steps
- Create connections as the flow owner (gate G-03).

## Exit criteria
- Deploy twice yields the same flows.
- A forced failure writes a log line and, on repeat, an alert.
