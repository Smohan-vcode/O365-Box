# T5-02  Numbering and document creation (F01, F02)

## Inputs
- Counters, Documents, Templates

## Outputs
- flows F01, F02

## Steps
1. F02 with concurrency 1: read the template's reference pattern, resolve year tokens, increment Counters, return the reference.
2. F01: validate required fields; refuse when the template is not ACTIVE or a used dictionary key is not CONFIRMED, writing the reason on the item.
3. Set created_by, domain, template version; write Events.

## Human steps
- None.

## Exit criteria
- Two items created together get different references.
- An item for a template with an unconfirmed key is refused with a clear message.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
