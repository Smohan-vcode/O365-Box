# S-04  Standard connector check and limits

## Inputs
- flows/catalogue.yaml
- expected-state/standard-connectors.yaml

## Outputs
- spikes/findings/S-04.md

## Steps
1. For every action each flow needs, confirm in the designer that the connector and action carry no premium mark: SharePoint copy file, update file properties, grant access, stop sharing, send an HTTP request to SharePoint; Outlook shared-mailbox trigger and send-from-shared; Approvals start and wait; Forms trigger; task creation.
2. Record the daily request allowance for the base licence and estimate use: 50 documents a month, 200 inbound mails a day, hourly reminders.
3. List any action that is premium and the free alternative, or mark the flow as needing an upgrade.

## Human steps
- None.

## Exit criteria
- Every flow in the catalogue is confirmed standard or moved to upgrades/.
- Estimated use is under one fifth of the allowance, or the finding flags the flow that exceeds it.

- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
