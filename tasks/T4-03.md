# T4-03  Template conversion

## Inputs
- spikes/findings/S-01.md

## Outputs
- engine/templates/convert
- command: box build templates

## Steps
1. For each buildable template, apply the S-01 method: replace deal, constant, note and reference occurrences with bound content controls, in reverse document order.
2. Leave choice occurrences as text; set needs_manual_edit.
3. Replace never_store occurrences with an underlined gap.
4. Verify: no confirmed non-choice bracket remains; page count of a PDF export equals the source's.
5. Write converted files to a build folder; never modify Source.

## Human steps
- None.

## Exit criteria
- The mutual NDA template converts with zero remaining bound brackets and an equal page count.
- Re-running produces identical files.
- A template with alternatives is flagged.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
