# T2-03  DNS records and DKIM

## Inputs
- configuration `dns`

## Outputs
- engine/terraform/dns/ (Cloudflare adapter) and the adapter interface for route53, azure, godaddy, manual (SPEC §3)
- command: box apply dkim

## Steps
1. Terraform: MX to the tenant's mail protection host; SPF `v=spf1 include:spf.protection.outlook.com -all`; the two DKIM selector CNAMEs; DMARC from a variable starting at none; TLS-RPT; MTA-STS record and policy host; CAA; reject records for non-mail hosts and domain aliases; autodiscover CNAME.
2. Read the DKIM CNAME targets from Exchange, write them to Terraform variables, then enable DKIM signing.
3. Fail the plan if Cloudflare Email Routing is enabled on the zone.

## Human steps
- None.

## Exit criteria
- `dig` returns every record.
- DKIM status is enabled.
- Second apply reports no changes.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
