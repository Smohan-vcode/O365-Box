# T14-12  Audit, alert policies and log export

## Inputs
- resolved settings for the areas `purview` (audit, alerts) and `entra` (log export)

## Outputs
- step `policy.audit`: alert policies
- weekly scheduled job: activity export (SPEC §18.8)

## Steps
1. Confirm the unified audit log and mailbox auditing are on.
2. Create the six alert policies routed to the alerts address; trigger each once on the test tenant.
3. Export administrator and sign-in activity weekly to the Compliance site's `Evidence` library, with one Evidence item per export.

## Human steps
- None.

## Exit criteria
- Each alert fires in its test.
- An export file exists for the previous week.
- No export contains a `never_store` value or a secret.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
