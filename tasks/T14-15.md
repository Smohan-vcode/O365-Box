# T14-15  Evidence per requirement and monthly coverage

## Inputs
- policy/requirements.yaml > evidence
- T10-01 collectors

## Outputs
- collectors named on requirements
- monthly coverage report

## Steps
1. Implement each collector named in requirements.yaml with T10-01's collector framework; one Evidence item per requirement per period; set `last_evidence_at` on the Requirements item.
2. Monthly: resolved coverage plus live verification plus the tenant's secure score, written to the Compliance site and the Requirements list.
3. Procedural requirements of the selected frameworks become recurring ControlTasks.

## Human steps
- None.

## Exit criteria
- Every enforced requirement has evidence for the current period.
- The monthly report matches `box check policy.<area>` for every area on the same day.
- A framework that is not selected creates no tasks or schedules.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
