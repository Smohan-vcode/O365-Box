# T6-01  People list applied by the pipeline

## Inputs
- People list

## Outputs
- command: box apply people
- hourly pipeline job

## Steps
1. For each active People item not yet applied: create the account with a temporary access pass, assign the plan on the item, add role and access groups; write applied_at or apply_error.
2. For an item set inactive: block sign-in, remove groups, release the licence, open the leaver checklist.
3. Refuse a plan change that would exceed purchased licences; report it on the item.
4. Open the joiner checklist from defaults/checklists.yaml.

## Human steps
- None.

## Exit criteria
- Adding an item creates the account and memberships within one run.
- Repeating the run changes nothing.
- Only owners can edit the list.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
