# T7-01  Setup list and views

## Inputs
- the orchestrator's event stream (SPEC §14.2)
- defaults/stages.yaml

## Outputs
- command: box sync setup

## Steps
1. Write every step and gate to the Setup list from the event stream.
2. Views: by track; waiting on a person; failed or drifted; stage reached.
3. Manual steps: evidence is a required attachment; a column rule prevents DONE without it.

## Human steps
- None.

## Exit criteria
- Setup has one item per step and gate in the configured modules.
- A manual step cannot be saved as DONE without an attachment.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
