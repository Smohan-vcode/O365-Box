# T4-01  Template source scan

## Inputs
- Legal/Templates/Source: the pack's Word files and catalogue, uploaded in onboarding step 5
- configuration `legal`

## Outputs
- command: box build scan
- `Bindings` list rows (suggested kind and key per occurrence)

## Steps
1. Match each file name to the pattern; read the header block for reference pattern, framework and version.
2. Extract every bracket occurrence with context; compare with existing `Bindings` rows; report added, missing and changed rows.
3. For a new pack version, carry confirmed rows forward where text and context are unchanged.

## Human steps
- None.

## Exit criteria
- Every file in the pack is scanned; on a second run the extraction equals the `Bindings` rows.
- A changed source file is reported with the exact rows affected.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
