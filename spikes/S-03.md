# S-03  Deploying the flow solution from source under the included licence

## Inputs
- flows/catalogue.yaml

## Outputs
- spikes/findings/S-03.md

## Steps
1. Create a solution with one flow using only the SharePoint connector and one child flow; export and unpack it with the Power Platform CLI.
2. Import it into the default environment of the test tenant as the pipeline identity; bind the connection reference to the flow owner's connection.
3. Turn the flow on and run it under an account with only the base subscription.
4. Confirm child flows and environment variables work under that licence.
5. If import or run is refused for licensing, test the fallback: non-solution flows imported from package files, with the manual steps counted.

## Human steps
- Create the SharePoint connection as the flow owner.

## Exit criteria
- A solution flow with a child flow runs under the base licence, or the finding states the fallback and its manual steps.
