# Document and file management policy

{{dictionary.company.legal_name}} · Version {{generated.version}} · Approved: {{generated.date}} · Next review {{generated.next_review}}

## 1. Purpose

This policy sets out where company files live, how they are organised and shared, and how they are kept safe from loss.

## 2. Where files live

- Company files are kept in the company's sites and libraries, not on local disks, removable storage or personal cloud services.
- Each site has a purpose and an owner group. Records sites (legal, finance, people, corporate, sales) follow the structure set by the company and are not reorganised by hand.
- Personal working files are kept in your company file storage. The Desktop, Documents and Pictures folders on company computers are saved there automatically.
- New sites, teams and groups are created only by administrators, on request to the owner.

## 3. Naming and versions

- Use clear names that say what the document is. Legal documents carry the reference the system gives them; do not rename them.
- Every library keeps version history. Edit the existing file rather than saving copies under new names.
- Deleted files can be recovered for a limited period. Ask an administrator if you delete something by mistake.

## 4. Sharing

- Share outside the company only with named people. Anonymous links are off and guest links expire.
- Share the smallest set of files that does the job, for the shortest time.
- From a device the company does not manage, files can be viewed in the browser but not downloaded, printed or synchronised.
- Files synchronise only to managed devices and only to the company's own tenant.

## 5. Access

Access to sites and libraries is granted to groups, not to individuals. Per-file permissions are used only where the system sets them for a stated reason. Site permissions are reviewed every quarter (PRC-06).

## 6. Leaving

When a person leaves, their files remain the company's. Their manager decides what is kept, moved or deleted under the retention schedule (POL-07).
