# T3-02  Libraries and permissions

## Inputs
- configuration `structure.sites[].libraries`

## Outputs
- command: box apply libraries

## Steps
1. Create libraries with versioning; where `access` is set, break inheritance and grant exactly those groups.
2. Add a required `Classification` choice column with the site's default.
3. Libraries with `content_types: generated` are prepared for T4.

## Human steps
- None.

## Exit criteria
- Every library exists with the declared access.
- A member of the sales group can read Legal/Templates and nothing else in Legal.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).

## Status notes
- 2026-11-21, test tenant: 31 libraries with versioning, Classification column, folders and per-library access (Legal/Templates: legal owners, sales readers; Executed inbox: signers). Second apply reports no changes. Not yet tested with a sales user's sign-in (needs a second licensed test user).
