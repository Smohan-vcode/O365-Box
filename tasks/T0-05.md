# T0-05  Pipeline and scheduled jobs

## Inputs
- .github/workflows/
- SPEC §18.8

## Outputs
- validate.yml, release.yml in this repository
- hourly.yml, weekly.yml templates for a company's copy
- command: `box handoff`

## Steps
1. On pull request: `go test`, Pester, `box config validate examples/acme`, `box check-literals`, `box check-connectors`, terraform validate, `box plan` against examples/acme with recorded responses.
2. Release: build `box` for Windows, macOS and Linux.
3. `box handoff`: set repository variables and secrets in the company's private copy and enable the scheduled workflows.
4. Hourly: people apply and role sync. Weekly: drift and evidence. Both read the configuration from the tenant.

## Human steps
- None.

## Exit criteria
- A pull request adding a company literal fails validation.
- A scheduled run on the test tenant reads the configuration from the tenant and plans no changes.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
