# T15-01  Directory mode: cloud or hybrid

## Inputs
- SPEC §24; docs/spec-changes.md SC-23 A
- choice `directory.mode`

## Outputs
- discovery reads onPremisesSyncEnabled and sync status
- module `hybrid`: Cloud Sync configuration checks, password hash sync, writeback; gate `cloud-sync-agent` with guide and check
- settings in the catalogue for hybrid (core tier, capability free or entra_p1)

## Steps
1. Detect a synchronised directory and pre-select the choice.
2. Cloud: confirm no sync is configured and devices are Entra-joined (with T14-05).
3. Hybrid: guide the Cloud Sync agent install (gate) and check its configuration through Graph; on-premises hardening is a checklist only.
4. Exclude Entra Domain Services and any paid feature (R2).

## Human steps
- Install the Cloud Sync agent on an existing server (hybrid only).

## Exit criteria
- Cloud mode on the test tenant reports no sync and no domain services.
- Hybrid mode's gate check reads the agent's health.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
