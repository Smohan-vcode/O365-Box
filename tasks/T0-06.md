# T0-06  Configuration store

## Inputs
- SPEC §9, §18.4 step 8, §21

## Outputs
- engine/internal/config
- store steps: hub, Admin site, Configuration library, Setup, Events and Dictionary lists
- commands: `box config show | export | import [--legacy]`; `box check-literals --from-tenant`

## Steps
1. Encrypted local draft (AES-256-GCM, key in the OS keychain), saved after every change.
2. Store steps: create the Admin site and lists; upload `box-config.yaml`; seed the Dictionary; copy run state; delete the draft.
3. Load and save with versions; each save writes one Events item with who and what.
4. Export and import as an encrypted file; `--legacy` reads the v1.0 layout from a local directory outside the repository.

## Human steps
- None.

## Exit criteria
- A configuration saved twice yields two versions and two Events items.
- After upload no draft file remains.
- An exported file cannot be read without its passphrase.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
