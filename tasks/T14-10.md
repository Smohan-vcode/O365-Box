# T14-10  Sensitivity labels

## Inputs
- resolved settings for the area `purview` (labels)
- configuration `structure.sites[*].classification`

## Outputs
- step `policy.labels`: labels, label policy, site labels

## Steps
1. Create the four labels (Public, Internal, Confidential, Restricted; no sub-labels, SC-31) with their markings and the Restricted encryption.
2. Publish the label policy: default Internal, label mandatory, justification to lower.
3. Enable labels for sites and groups; apply the site label matching each site's `classification` in the configuration.
4. Add the labels to the template content types (T4) so generated documents carry their class.

## Human steps
- None.

## Exit criteria
- A new document is Internal by default.
- A Restricted document cannot be opened by an outside account.
- Each site carries the label of its classification.
- A second apply plans no changes.
