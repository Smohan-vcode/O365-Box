# T3-01  Hub and sites

## Inputs
- configuration `structure.sites` (recommended in defaults/structure.yaml)
- baseline/sharepoint.yaml

## Outputs
- command: box apply sites

## Steps
1. Apply tenant sharing settings.
2. Create the hub and each site; associate to the hub; set site sharing; grant access groups to the site's owner, member or visitor group; remove every individual.
3. Record site ids in configuration `ids`; export permissions to evidence.

## Human steps
- None.

## Exit criteria
- Sites exist with only groups as members.
- External sharing is off where declared.
- Second apply reports no changes.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
