# T1-05  Identity baseline

## Inputs
- effective baseline: configuration `baseline` (preset plus overrides) over baseline/presets/
- expected-state/baseline-coverage.yaml

## Outputs
- command: box apply baseline identity

## Steps
1. Apply each setting by the method the coverage file names.
2. Create Conditional Access policies with the exclusion group on every one; create in report-only when `start_state` says so.
3. Refuse to enable any blocking policy unless `box check break-glass` passes in the same run.
4. Turn security defaults off only after CA01 and CA02 are enabled. Without the `conditional_access` capability, keep security defaults on (SPEC §20.3).
5. Open gate G-05, then verify the founder holds no directory role.

## Human steps
- Remove the founder's standing administrator role (gate G-05).

## Exit criteria
- Every identity setting equals the declared value.
- Every policy excludes the break-glass group.
- Legacy authentication sign-in is blocked in a test.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
