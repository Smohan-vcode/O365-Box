# T14-11  Data loss prevention policies

## Inputs
- resolved settings for the area `purview` (DLP-01 to DLP-10)
- configuration `policy.consumer_mail_domains`, `structure.sites`; Dictionary `company.marker_terms`

## Outputs
- step `policy.dlp`: ten policies
- test cases using only fictional values from examples/acme/
- gate G-08 in engine/gates.yaml

## Steps
1. Create each policy for mail, SharePoint and OneDrive with the built-in information types; site-scoped policies use the sites in the configuration's `structure`.
2. DLP-08 and DLP-09 use the consumer domain list; DLP-09 compares the sender's name parts with the recipient address.
3. DLP-10 builds a keyword type from the marker terms; skip it while the list is empty.
4. Start every policy in test with policy tips; route incident reports to the alerts address.
5. Write one test message or file per policy and record the expected outcome.
6. After the audit period, wait at gate G-08 for the owner's review of matches; tune thresholds, then enforce.

## Human steps
- Review audit-period matches before enforcement (gate G-08).

## Exit criteria
- Each test case produces the expected tip, block or report.
- A file labelled Restricted cannot be shared or mailed outside.
- Mail with an attachment to a consumer domain asks for a justification.
- No policy uses a location or condition outside the plan.

- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
