# T4-05  Dictionary views and completeness

## Inputs
- Dictionary, Bindings

## Outputs
- views and a completeness report

## Steps
1. Views on Dictionary: open items, by owner, by number of templates using the key.
2. `box report completeness`: per template READY or INCOMPLETE; written to the Admin site weekly.

## Human steps
- None.

## Exit criteria
- A template whose keys are all CONFIRMED reports READY.
