# T14-05  Apply: Windows devices and Office apps

## Inputs
- resolved settings for the areas `intune-windows` and `m365-apps`

## Outputs
- steps `policy.intune-windows` and `policy.m365-apps`
- PolicySettings items

## Steps
1. Create compliance, disk encryption, firewall, antivirus, attack surface reduction, account protection, update ring and settings-catalogue profiles named by setting group; extend, do not recreate, what T1-04 made.
2. Onboard devices to endpoint detection automatically.
3. Run on one pilot device in the pilot group for the audit period and record blocked events before enforcing.
4. Apply in audit, then enforce by the rollout stage.

## Human steps
- None.

## Exit criteria
- `box check policy.intune-windows` passes on the test tenant.
- `box check policy.m365-apps` passes on the test tenant.
- Each staged setting has audit evidence for `policy.rollout.audit_days` before it is enforced.
- A second apply plans no changes.
