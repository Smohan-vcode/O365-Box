# T15-03  Azure provider and discovery

## Inputs
- docs/spec-changes.md SC-23 C
- choice `azure.subscription`

## Outputs
- provider `azure` (Azure Resource Manager over REST, no Azure module)
- discovery of subscriptions and management groups
- policy/settings/azure.yaml: the free settings, capability azure_subscription
- bundle `azure` (Azure roles at the company's management group) and gate `azure-subscription` for creating one

## Steps
1. Read subscriptions with the pipeline app (needs the azure bundle) and pre-fill the choice.
2. Write the Azure settings into the catalogue with requirements and frameworks; map each (ARM path, payload, read-back).
3. Gate for creating a pay-as-you-go subscription, with the cost note.

## Human steps
- Create the subscription (only when the owner chose 'create').

## Exit criteria
- No Azure step runs when the choice is 'none'.
- Every Azure setting is mapped, free, and verified read-only on a test subscription.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
