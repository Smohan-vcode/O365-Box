# T5-04  Approval (F04)

## Inputs
- ApprovalRules, RoleAssignments, Delegations

## Outputs
- flow F04

## Steps
1. Select the most specific active rule: template code over domain; evaluate condition.
2. Resolve approvers from RoleAssignments with active delegations; apply the self-approval safeguard.
3. Start an approval with the document link and terms; on approve continue or set READY; on reject set DRAFT with the comment; second step when configured.
4. Write Approvals and Events for each decision.

## Human steps
- None.

## Exit criteria
- Unchanged-template NDA goes to READY with no approval.
- With two holders the sender is not asked; with one, self-approval is recorded.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
