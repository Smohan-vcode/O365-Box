# T0-08  Approval gate: proposals and approve before apply

## Inputs
- SPEC §25.1; docs/spec-changes.md SC-25 A

## Outputs
- `box plan --proposal` / proposal file per tenant, `box approve`, apply refuses unapproved changes, approval Events item

## Human steps
- None.

## Exit criteria
- An apply with an unapproved change applies nothing for that step and names the change.
- Approving all, an area or one change, then applying, applies exactly those.
- A rejected change becomes an exception with the reason.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
