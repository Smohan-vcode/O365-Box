# T14-06  Apply: macOS devices

## Inputs
- resolved settings for the area `intune-macos`

## Outputs
- step `policy.intune-macos`
- gate G-07 in engine/gates.yaml
- PolicySettings items

## Steps
1. Create compliance, FileVault, firewall, Gatekeeper, update and restrictions profiles, and the approvals the endpoint protection agent needs.
2. Wait at gate G-07 for the Apple push certificate; its check reads the certificate state and expiry.
3. Apply in audit, then enforce by the rollout stage.

## Human steps
- Create the Apple push certificate (gate G-07).

## Exit criteria
- `box check policy.intune-macos` passes on the test tenant.
- Each staged setting has audit evidence for `policy.rollout.audit_days` before it is enforced.
- A second apply plans no changes.
