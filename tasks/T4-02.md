# T4-02  Bindings confirmation check

## Inputs
- `Bindings` list rows written by T4-01

## Outputs
- command: box check bindings
- Bindings and Templates list items

## Steps
1. Validate each confirmed row: kind set; constant and note rows have a key present in the `Dictionary`; deal rows have a field name valid as a column; rows listed under never_store in the catalogue are marked so.
2. Report per template: total, confirmed, outstanding; a template is buildable when all are confirmed.
3. Create or update `Templates` items from the pack catalogue in Legal/Templates/Source.

## Human steps
- Owner or counsel confirms each `Bindings` row in the TUI's template screen or the list form.

## Exit criteria
- An unconfirmed row keeps its template NEEDS_REVIEW.
- A constant row with an unknown key fails the check.

## Evidence
- Engine: front matter `status: DONE` with the commit reference. Tenant: the step's `Setup` list item and evidence artefact (SPEC §14).
