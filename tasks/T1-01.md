# T1-01  Break-glass accounts and exclusion group

## Inputs
- configuration `users`
- baseline/identity.yaml > break_glass

## Outputs
- command: box check break-glass

## Steps
1. Verify the accounts bootstrap created exist, are cloud-only, unlicensed, Global Administrator, with FIDO2 registered.
2. Create the exclusion group and add both accounts.
3. Create an alert: any sign-in by these accounts mails the alerts address.

## Human steps
- Register FIDO2 keys (gate G-02).

## Exit criteria
- Check passes.
- A test sign-in produces the alert.
